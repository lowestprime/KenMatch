# KenMatch category icons

These are repository-tracked, theme-specific reference exports for the KenMatch category identity system.

- `dark/` uses a true-black surface and white semantic glyphs.
- `light/` uses a true-white surface and near-black semantic glyphs.
- The five-stop perimeter is identical to the finalized KenMatch product mark.
- The live application uses the same core geometry inline and adds dynamic stage and allocation indicators.
- These static exports intentionally contain no task-specific stage or allocation state.

All SVGs use a `96 × 96` viewBox, include accessible title/description elements, and contain no scripts, raster images, external references, or fonts.
